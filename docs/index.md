# PACS and AMSC Examples

This repository collects examples and exercises for two Master's-level courses taught by [Luca Formaggia](https://formaggia.faculty.polimi.it/) at Politecnico di Milano, Italy:

- **Advanced Programming for Scientific Computing (PACS)** — *Programmazione Avanzata per il Calcolo Scientifico* in Italian — introduces modern C++ for scientific computing, including object-oriented and generic programming, code design, debugging and profiling, numerical libraries, and parallel programming with MPI and OpenMP.
- **Advanced Methods for Scientific Computing (AMSC)** develops advanced numerical and computational methods for scientific-computing applications within the High Performance Computing Engineering programme.

The course names, programmes, and teaching assignments are listed in the [Politecnico di Milano course catalogue](https://onlineservices.polimi.it/manifesti/manifesti/controller/ricerche/RicercaPerDocentiPublic.do?EVN_DIDATTICA=EVENTO&aa=2025&ac_ins=0&jaf_currentWFID=main&k_cf=-1&k_corso_la=-1&k_doc=5386&lang=EN&sede=ALL_SEDI&semestre=ALL_SEMESTRI&tab_ricerca=1&tipoCorso=ALL_TIPO_INSEGNAMENTO).
